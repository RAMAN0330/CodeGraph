C. Hybrid hierarchy — recommended

Explicit folder/file/function levels with breadcrumbs; zoom only reveals labels within the current level. Predictable and still quick to scan.

Recommended level model

L0 repository packages/root folders → L1 nested folders/modules → L2 files → L3 classes/functions. At every level, only nodes in the current scope render; names appear for selected, hovered, and sufficiently separated nodes.
